=========================================
TUTORIAL MENAMPILKAN DATA
Aplikasi: Peminjaban Alat / GameVault (UKK RPL - Laravel)
=========================================

Halo! Tutorial ini menjelaskan langkah demi langkah
bagaimana cara menampilkan data di project Laravel Anda.

Project ini adalah aplikasi peminjaman alat/konsol dengan:
- Backend: Laravel 11/12 (PHP 8.3) + Eloquent (MySQL)
- Frontend: Blade + Bootstrap 5 (template "Sneat") + Vite
- Tidak pakai API, semua halaman dirender langsung via Blade.

Alur dasar menampilkan data di project ini:
  Request -> Route -> Controller -> Eloquent Model -> View (Blade) -> Response HTML


BAB 1: SIAPAN LINGKUNGAN (wajib sebelum menampilkan data)

  composer install
  npm install
  cp .env.example .env
  php artisan key:generate
  php artisan migrate --seed
  npm run build
  php artisan serve

=========================================
LANGKAH 3: MEMBUAT METHOD index DI CONTROLLER
=========================================

File: app/Http/Controllers/CategoryController.php

  public function index(Request $request): View
  {
      $this->cekRole('admin');

      $query = Category::withCount('consoles');

      if ($request->query('q')) {
          $query->where('name', 'like', '%'.$request->query('q').'%');
      }

      $categories = $query->orderBy('name')->paginate(10)->withQueryString();

      return view('categories.index', [
          'categories' => $categories,
          'cari' => $request->query('q'),
      ]);
  }

Catatan penting di dalam query:
  1. cekRole('admin') -> membatasi akses, dari Controller base (app/Http/Controllers/Controller.php)
  2. withCount('consoles') -> eager loading + menghitung jumlah relasi (consoles_count)
  3. where('name', 'like', '%'.$request->query('q').'%') -> pencarian
  4. paginate(10) -> pagination, 10 data per halaman
  5. withQueryString() -> biarkan query ?q=... tetap utuh saat paginasi
  6. orderBy('name') -> urut data

LANGKAH 4: CONTOH QUERY UNTUK HALAMAN TRANSAKSI
=========================================

File: app/Http/Controllers/TransactionController.php

  public function index(): View
  {
      $this->cekRole('pengguna');

      $transactions = Transaction::with('console')
          ->where('user_id', auth()->id())
          ->orderByDesc('id')
          ->paginate(10);

      return view('transactions.index', compact('transactions'));
  }

Untuk halaman detail (show), selalu load relasi yang dipakai di view:

  public function show(Transaction $transaction): View
  {
      $this->cekRole('pengguna', 'petugas', 'admin');

      if (auth()->user()->isPengguna() && $transaction->user_id !== auth()->id()) {
          abort(403, 'Pengajuan ini bukan milik Anda.');
      }

      $transaction->load(['console.category', 'approver', 'retur']);

      return view('transactions.show', compact('transaction'));
  }

LANGKAH 6: TAMPILKAN DATA DI VIEW BLADE

File: resources/views/categories/index.blade.php

  @extends('layouts.app')

  @section('title', 'Data Kategori')

  @section('content')
    <div class="row">
      <div class="col-12">
        <div class="card">
          <div class="card-header d-flex justify-content-between align-items-center">
            <h5 class="mb-0">Data Kategori</h5>
            <a href="{{ route('categories.create') }}" class="btn btn-primary btn-sm">
              <i class="bx bx-plus me-1"></i> Tambah Kategori
            </a>
          </div>

          <div class="table-responsive text-nowrap">
            <table class="table">
              <thead>
                <tr>
                  <th>No</th>
                  <th>Nama</th>
                  <th>Slug</th>
                  <th>Deskripsi</th>
                  <th>Jumlah Objek</th>
                  <th>Aksi</th>
                </tr>
              </thead>
              <tbody class="table-border-bottom-0">
                @forelse ($categories as $category)
                  <tr>
                    <td>{{ $categories->firstItem() + $loop->index }}</td>
                    <td><strong>{{ $category->name }}</strong></td>
                    <td>{{ $category->slug }}</td>
                    <td>{{ $category->description ?? '-' }}</td>
                    <td><span class="badge bg-label-primary">{{ $category->consoles_count }}</span></td>
                    <td>
                      <a href="{{ route('categories.edit', $category) }}" class="btn btn-sm btn-warning">Edit</a>
                      <form action="{{ route('categories.destroy', $category) }}" method="POST" class="d-inline" onsubmit="return confirm('Hapus kategori ini?')">
                        @csrf
                        @method('DELETE')
                        <button class="btn btn-sm btn-danger" type="submit">Hapus</button>
                      </form>
                    </td>
                  </tr>
                @empty
                  <tr>
                    <td colspan="6" class="text-center text-muted">Belum ada data kategori.</td>
                  </tr>
                @endforelse
              </tbody>
            </table>
          </div>

          @if ($categories->hasPages())
            <div class="card-body">
              {{ $categories->links() }}
            </div>
          @endif
        </div>
      </div>
    </div>
  @endsection

Penjelasan Blade yang dipakai:
  - @extends('layouts.app')          -> memanggil layout utama
  - @section('title', '...')         -> judul halaman
  - @section('content')              -> isi konten
  - @forelse ($data as $item)       -> loop data, @empty -> tampil kalau tidak ada data
  - {{ $data->firstItem() + $loop->index }} -> nomor urut
  - {{ route('nama.route', $item) }} -> generate URL via nama route
  - {{ $data->links() }}              -> pagination

  public function index(): View
  {
      $user = auth()->user();

      if ($user->isPengguna()) {
          return view('dashboard.pengguna', [
              'totalPengajuan' => Transaction::where('user_id', $user->id)->count(),
              'menunggu' => Transaction::where('user_id', $user->id)->where('status', 'pending')->count(),
              'dipinjam' => Transaction::where('user_id', $user->id)->where('status', 'borrowed')->count(),
              'selesai' => Transaction::where('user_id', $user->id)->where('status', 'returned')->count(),
          ]);
      }

      if ($user->isPetugas()) {
          return view('dashboard.petugas', [
              'menunggu' => Transaction::where('status', 'pending')->count(),
              'disetujui' => Transaction::where('status', 'approved')->count(),
              'dipinjam' => Transaction::where('status', 'borrowed')->count(),
              'terlambat' => Transaction::where('status', 'late')->count(),
          ]);
      }

      return view('dashboard.admin', [
          'totalKategori' => Category::count(),
          'totalObjek' => Console::count(),
          'objekTersedia' => Console::where('status', 'available')->count(),
          'totalUser' => User::count(),
          'menunggu' => Transaction::where('status', 'pending')->count(),
          'dipinjam' => Transaction::where('status', 'borrowed')->count(),
          'aktivitasTerbaru' => ActivityLog::with('user')->orderByDesc('id')->limit(5)->get(),
          'objekPopuler' => Console::withCount('transactions')->orderByDesc('transactions_count')->limit(5)->get(),
      ]);
  }

CONTOH URUTAN LENYAP UNTUK MENAMPILKAN 1 DATA
=========================================

  1. routes/web.php

  2. app/Http/Controllers/XxxController.php
       -> method index(): query Eloquent -> paginate -> with -> return view

  3. resources/views/xxx/index.blade.php
       -> @extends('layouts.app')
       -> @section('content')
           -> @forelse ($data as $item) ... @empty ... @endforelse
           -> {{ $data->links() }}

  4. resources/views/partials/badge-status.blade.php (jika pakai status)

  5. app/Models/ -> pastikan relasi + casts sudah benar

  6. php artisan serve -> cek di browser


=========================================
TROUBLESHOOTING / ERROR YANG SERING KELIHIRAN

  1. Error "Attempted to read property on null" -> relasi belum di-load.
        Solusi: tambahkan with('relasi') di query, contoh:
        Transaction::with('console')->...

  2. Error "Class not found" -> cek use statement di controller.

  3. Data tidak muncul di view -> pastikan nama variable yang di-pass ke view
     sama persis dengan yang dipakai di Blade.

  4. Pagination tidak tampil -> pastikan pakai $data->links() dan
     periksa package Laravel 11+ (default sudah ada).

  5. Search tidak jalan -> pastikan form GET ke route yang sama dan
     pakai ->withQueryString().

  6. 403 saat akses -> cek cekRole() di controller dan role user-nya.

  7. Tampilan kosong setelah data ada -> cek @forelse ... @empty, hapus cache:
        php artisan optimize:clear

=========================================
CATATAN PENTING

  - Semua controller di project ini mengembalikan View (Blade), BUKAN JSON.
  - Gunakan Eloquent, bukan query SQL mentah, untuk konsistensi.
  - Prioritaskan eager loading (with) untuk menghindari N+1 query.
  - Gunakan Form Request untuk validasi jika data masuk dari form.
  - Pagination wajib untuk data banyak (paginate, bukan get()).
